# Contributing

Describe the learner or teacher problem before changing code. Keep changes focused.

1. Run `node --test tests/*.test.mjs` and `node scripts/build-worker.mjs`.
2. Check small screens and keyboard navigation.
3. Preserve ownership, role boundaries and server-side scoring.
4. Never commit secrets, real contacts, student records or local databases.

AI-generated changes need the same review and validation as other changes.
